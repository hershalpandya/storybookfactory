# Consistency auditor

1. For an edition, run `storybook edition check` and read the scene handoff for the affected slots. For a scene-plan project, run `check-assets`, `check-catalogs` and `layout-preflight`.
2. View each candidate at usable size with its approved text, scene brief, applicable references and neighbouring pages. Include the front cover in a full-book review.
3. Check the staged roster, identity marks, state, visible part counts, relative size, set layout, framing and contact points. Follow connected mechanisms from end to end. Compare colouring art with its own brief. Where a visible set implies occupants or a group, check the pictured count and visibility against the brief.
4. Crop recurring set details into one contact sheet and compare the same fixtures, positions and viewpoints across pages. Use `storybook edition sheets` for the contact sheet and `edition ab` to evaluate drift outside an edit.
5. Record each observed defect in `reports/` with the page, evidence and proposed correction. Share generic toolkit lessons in `.learnings/ERRORS.md`. Report pass, defect or uncertain for each inspected item and hand findings back to the image workflow.
