# Book rendering

After approving the adaptation, staging `scenes.json` and registering passing image assets, create private book metadata. In format 3, run `storybook layout-preflight PROJECT METADATA` with the intended font before staging image calls. It checks story and cover text without artwork and records the picture boxes used by the renderer. A reviewed liaison stays together when lines wrap. The finished render uses the same metadata and font. In formats 2 and 3, put optional cover scenes in the scene plan under `covers.front` and `covers.back`. The renderer uses their registered illustration assets.

```json
{"title":"A kite", "author":"A storyteller", "dedication":"For a friend", "date":"2026", "back_title":"The end"}
```

Only `title` is required. Older version-1 plans can reference optional artwork with `cover_image` and `back_image` paths relative to the metadata file. Review that artwork before rendering. Run `storybook render PROJECT metadata.json NEW_OUTPUT_DIRECTORY`. The output directory must not already exist. The command validates the approved adaptation, scene plan and registered image hashes, then writes `reading.pdf`, `single-sided.pdf`, `duplex.pdf`, `single-sided-printer-safe.pdf`, `duplex-printer-safe.pdf`, `duplex-bound.pdf` and `reviewed-text.json`. The JSON retains the exact adaptation, contextual marks and page-to-passage mapping, because the shaped PDF lettering is rasterized. Treat the output as private if the story is private.

All PDFs use one A4 landscape page per sheet side. The regular print files have sewing marks 9 mm from the physical binding edge. The duplex file is ordered for short-edge flip: even PDF pages use the right binding edge and colouring on the left. When the cover, story and back would total an odd number of pages, a marked blank page is inserted immediately before the back cover in the duplex file; the other files contain no inserted page. The printer-safe versions center and proportionally shrink page content into an 8 mm minimum margin, darken grey pronunciation marks, and draw sewing marks 10.5 mm from the binding edge. Their scale is 194/210, approximately 92.38%: nominal 15 pt text becomes approximately 13.86 pt before printer scaling. The regular editions remain separate and retain 9 mm marks. An 8 mm margin is not printable on every device. The bound duplex file (`duplex-bound.pdf`) leaves room for sewing and folding: page content is scaled to 92% and shifted away from the binding, so artwork and text start about 34 mm from the binding edge on fronts and about 41 mm on backs, with about 18 mm at the outer edge; reading marks are darkened as in the printer-safe files and sewing marks sit 12 mm from the binding edge. Nominal 15 pt text becomes about 13.8 pt. `storybook edition build PROJECT OUTPUT --mode duplex-bound` renders only that file (repeat `--mode` for more).

Print on A4 landscape at **100% / Actual size**, one PDF page per sheet side; disable fit-to-page, booklet and multiple-pages-per-sheet settings. For duplex select **flip on the short edge**. Sew through the left edge of fronts; the right edge of backs aligns with it. Print and inspect one sheet first to check feed orientation, both sides, alignment and clipping before printing the book.

Marelle 2 is the bundled font for French CE1. Pillow must have libraqm support to shape text; an explicit `--font PATH` can select a suitable TrueType font for another language. Font coverage, shaping, annotation positioning and readability need human inspection, especially with a new script. The renderer fails on missing or stale assets and text that exceeds its layout; revise the scene pagination when text does not fit. Inspect every page for artwork, annotation, overlap and margins, and review the physical print and sewn proof. Registrations and approval flags record assertions; they do not verify artwork or language quality.

Edition reading previews compress opaque story illustrations as JPEG at their
existing pixel dimensions. Final builds and print modes use the original
artwork encoding path.
