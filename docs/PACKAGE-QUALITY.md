# Storybook quality checks

Use these checks to review a story from source through print proof.

| Issue | Toolkit check and remaining review |
| --- | --- |
| Beats omitted, duplicated, reordered, or source versions disagree | Use a private ordered source-to-draft-to-page ledger and document corrections and uncertainty. Adaptation validation requires every reviewed source passage to be cited without moving backward, and scene validation requires each adapted passage once in order. These structural mappings cannot confirm passage content or intra-passage beat order; a human must compare actual beats against all sources. |
| Character appearance, scarf, shearing, skin, size and perspective drift | Record page-specific states and inspect every image against the applicable local references and continuity checklist. Human judgment is required. |
| Actions, participants, rope geometry, accidents, refusals or knitting are misrepresented | Specify agency, sequence, props and distinct motivations in each relevant scene; inspect image and text together. Keep accidents gentle when requested. |
| Repeated, irrelevant or unsuitable illustrations and colouring art | Supply distinct per-page requests; format-3 intake rejects blank, undersized or pixel-identical artwork and supplies exact comparison images for returning subjects. A reviewer assesses novelty, relevance and suitability. |
| Title, ending or personal image differs from instructions | Verify exact metadata and final-page content with the owner; keep private images local and obtain agreement before external use. |
| Drafts, assets and approvals confused | Track pending/rejected/draft/approved states privately, preserve resumable work and stale-plan checks, and clearly label drafts. Require explicit human source, language, phonetic, image, layout and physical print/sewing reviews. Assertions and hashes cannot certify a review. |

The code checks print pixels and recorded observations. Narrative interpretation, anatomy judgments, source disagreements and physical print quality require reviewers. Edition image rounds can use an explicitly authorized external provider or the Gemini adapter. Offline fixture tests use a simulated provider. Local references, transcripts and private projects belong in ignored local directories.
